= Web Terminal

Abre una terminal dentro de la consola. El resto del lab se puede hacer desde ahí.

== Instalar Web Terminal

. Consola OpenShift → *Ecosystem* → *Software Catalog*
. Busca `Web Terminal`
. Instala *Web Terminal*. Deja los valores por defecto (*All namespaces* y el namespace recomendado).
. Espera *Succeeded*

== Abrir la terminal

. En la barra superior de la consola, icono de terminal
. *Start Terminal* / *Open Terminal*
. Comprueba:

[source,bash]
----
oc whoami
oc version
----

`oc whoami` debe devolver `kubeadmin`.

== Usuario admin

`kubeadmin` vale para Operators. El dashboard de OpenShift AI *no* lo acepta.

Define la contraseña (puedes cambiarla; por defecto `rhoai`):

[source,bash]
----
PASS='rhoai'
----

Desde esta terminal:

[source,bash]
----
echo "admin:$(openssl passwd -apr1 "$PASS")" > /tmp/htpasswd

oc create secret generic htpasswd-secret \
  --from-file=htpasswd=/tmp/htpasswd \
  -n openshift-config \
  --dry-run=client -o yaml | oc apply -f -

oc patch oauth cluster --type merge -p '{"spec":{"identityProviders":[{"name":"htpasswd","mappingMethod":"claim","type":"HTPasswd","htpasswd":{"fileData":{"name":"htpasswd-secret"}}}]}}'

oc adm policy add-cluster-role-to-user cluster-admin admin
----

Espera a que los pods de `openshift-authentication` estén `Ready`:

[source,bash]
----
oc wait --for=condition=Ready pods --all -n openshift-authentication --timeout=180s
----

== Cambiar Usuario

. Cierra sesión (esquina superior derecha)
. Entra como `admin` / `rhoai` (o la contraseña que hayas puesto en `PASS`)
. Abre otra vez el Web Terminal
. Comprueba:

[source,bash]
----
oc whoami
----

Debe devolver `admin`. El resto del lab se hace con este usuario.

Clona el repo en esta terminal:

[source,bash]
----
git clone https://github.com/pkstaz/rhoai-showroom.git
cd rhoai-showroom
----

Los `oc apply -f manifests/...` de los módulos siguientes se ejecutan desde ese directorio.

Helm 3, en `$HOME` (el Web Terminal no tiene `sudo`):

[source,bash]
----
mkdir -p "$HOME/bin"
export PATH="$HOME/bin:$PATH"
curl -fsSL https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | \
  USE_SUDO=false HELM_INSTALL_DIR="$HOME/bin" bash
grep -q 'HOME/bin' "$HOME/.bashrc" 2>/dev/null || echo 'export PATH="$HOME/bin:$PATH"' >> "$HOME/.bashrc"
helm version
----

== Verificar

[source,bash]
----
oc get csv -A | grep -i -E 'webterminal|devworkspace'
----

Debe aparecer al menos un CSV `Succeeded`.
