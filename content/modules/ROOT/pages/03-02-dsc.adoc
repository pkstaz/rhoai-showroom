= DataScienceCluster

El `DataScienceCluster` (`default-dsc`) activa los componentes de OpenShift AI que usa este lab.
Deja en `Managed` solo lo necesario; el resto queda `Removed` (o `Unmanaged` en el caso de Kueue, que ya instalaste como Operator en xref:03-00-operators.adoc[Prerrequisitos → Operadores base]).

NOTE: `ogx` en `Managed` es requisito del *Gen AI Studio → Playground*. Sin OGX, la UI puede listar endpoints pero no ofrece Playground.

NOTE: Si el DSC queda `Degraded` por `aigateway`, verifica el Operator de Connectivity Link (xref:04-01-operators-maas.adoc[Prerrequisitos → Operadores MaaS]) y re-aplica el DSC.

== Componentes de este lab

[cols="1,1,2"]
|===
|Componente |Estado |Para qué sirve

|`dashboard`
|Managed
|Consola web de OpenShift AI (ruta `rhods-dashboard` / `rhoai`).

|`workbenches`
|Managed
|Notebooks / workbenches en `rhods-notebooks`.

|`kserve`
|Managed
|Serving de modelos (InferenceServices / llm-d). Subcomponentes NIM, model cache y `modelsAsService` quedan `Removed`.

|`aipipelines`
|Managed
|AI Pipelines (Argo) sobre OpenShift Pipelines.

|`modelregistry`
|Managed
|Model Registry (namespace `rhoai-model-registries`).

|`aigateway`
|Managed
|AI Gateway. `modelsAsAService` queda `Removed` hasta Connectivity Link + gateway + Postgres (módulo 4).

|`ogx`
|Managed
|Motor del *Gen AI Studio → Playground*.

|`kueue`
|Unmanaged
|Usa el Operator de Kueue ya instalado (GPU Booking); el DSC no gestiona el Operator.

|`sparkoperator`
|Removed
|No se usa en este lab.

|`feastoperator`
|Removed
|Feature store; fuera de alcance.

|`trustyai`
|Removed
|EvalHub / TrustyAI se habilitan más adelante (módulo 12).

|`ray`
|Removed
|Distributed training Ray; fuera de alcance.

|`mlflowoperator`
|Removed
|MLflow se activa con EvalHub (módulo 12) y lo reutilizan Prompt Registry / EvalHub.

|`trainer` / `trainingoperator`
|Removed
|Training operators; fuera de alcance.

|`llamastackoperator`
|Removed
|Llama Stack legado; el lab usa `ogx`.

|`mcplifecycleoperator`
|Removed (módulo 20 → Managed)
|MCP Catalog / `MCPServer` (Technology Preview; docs piden OCP 4.22+).
|===

== Manifiesto

.default-dsc.yaml (click para expandir)
[%collapsible]
====
[source]
----
apiVersion: datasciencecluster.opendatahub.io/v2
kind: DataScienceCluster
metadata:
  name: default-dsc
  labels:
    app.kubernetes.io/name: datasciencecluster
spec:
  components:
    ogx:
      managementState: Managed
    sparkoperator:
      managementState: Removed
    kserve:
      wva:
        managementState: Removed
      rawDeploymentServiceConfig: Headless
      nim:
        airGapped: false
        managementState: Removed
      modelCache:
        managementState: Removed
      modelsAsService:
        managementState: Removed
      managementState: Managed
    modelregistry:
      registriesNamespace: rhoai-model-registries
      managementState: Managed
    feastoperator:
      managementState: Removed
    trustyai:
      eval:
        lmeval:
          permitCodeExecution: deny
          permitOnline: deny
      mcpGuardrailsMode: false
      managementState: Removed
    aipipelines:
      argoWorkflowsControllers:
        managementState: Managed
      managementState: Managed
    ray:
      managementState: Removed
    kueue:
      autoCreateQueues: false
      defaultClusterQueueName: default
      defaultLocalQueueName: default
      managementState: Unmanaged
    workbenches:
      workbenchNamespace: rhods-notebooks
      managementState: Managed
    mlflowoperator:
      managementState: Removed
    dashboard:
      managementState: Managed
    trainer:
      managementState: Removed
    llamastackoperator:
      managementState: Removed
    aigateway:
      managementState: Managed
      modelsAsAService:
        managementState: Removed
    trainingoperator:
      managementState: Removed
----
====

== Instalar por terminal

Desde la raíz del repo (crea o actualiza `default-dsc`):

[source,bash]
----
oc apply -f manifests/default-dsc.yaml
----

== Verificar

Espera a que el DSC quede listo (puede tardar 5–15 min) y muestra un resumen legible:

[source,bash]
----
printf '%-36s %-12s %s\n' "RECURSO" "ESTADO" "DETALLE"
printf '%-36s %-12s %s\n' "------------------------------------" "------------" "----------------"

oc wait --for=condition=Ready dsc/default-dsc --timeout=900s >/dev/null 2>&1 && \
  printf '%-36s %-12s %s\n' "DataScienceCluster/default-dsc" "OK" "Ready=True" || \
  printf '%-36s %-12s %s\n' "DataScienceCluster/default-dsc" "PENDIENTE" "$(oc get dsc default-dsc -o jsonpath='{.status.conditions[?(@.type=="Ready")].reason}' 2>/dev/null || echo 'sin Ready')"

ogx=$(oc get dsc default-dsc -o jsonpath='{.status.conditions[?(@.type=="OGXReady")].status}' 2>/dev/null)
if [ "$ogx" = "True" ]; then
  printf '%-36s %-12s %s\n' "OGXReady" "OK" "True"
else
  printf '%-36s %-12s %s\n' "OGXReady" "PENDIENTE" "${ogx:-desconocido}"
fi

pods=$(oc get pods -n redhat-ods-applications --no-headers 2>/dev/null | awk '$3=="Running"{c++} END{print c+0}')
total=$(oc get pods -n redhat-ods-applications --no-headers 2>/dev/null | wc -l | tr -d ' ')
printf '%-36s %-12s %s\n' "Pods redhat-ods-applications" "OK" "${pods}/${total} Running"
----

== URL del dashboard

[source,bash]
----
echo "https://$(oc get route -n redhat-ods-applications -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{.spec.host}{"\n"}{end}' | awk '/dashboard|rhoai/{print $2; exit}')"
----

Abre esa URL como `admin` (no `kubeadmin`).
