= Operadores MaaS

Antes de Habilitar MaaS hacen falta tres operadores de plataforma:

* *cert-manager Operator for Red Hat OpenShift* — emite los certificados TLS que usa el stack de *Gateway API* / *AI Gateway* en las rutas de MaaS.
* *Red Hat Connectivity Link* — capa de *Gateway API* + políticas (Kuadrant) delante del *AI Gateway*. Instala *solo el Operator* ahora (`openshift-operators`, All namespaces); el `GatewayClass` y la instancia Kuadrant van en xref:04-00-connectivity.adoc[GatewayClass y Kuadrant].
* *Leader Worker Set Operator* — coordina pods *líder + workers* para inferencia distribuida; *llm-d* lo usa al desplegar modelos (módulo 8). Namespace `openshift-lws-operator`, canal `stable-v1.0`.

Canal y namespace: los que propone el *Software Catalog*, salvo que la tabla indique otra cosa.

== Validar instalados y pendientes

Ejecuta esto *antes* de instalar (y otra vez al final). `OK` = CSV `Succeeded`; `PENDIENTE` = aún no está o no terminó:

[source,bash]
----
printf '%-42s %-14s\n' "OPERADOR" "ESTADO"
printf '%-42s %-14s\n' "------------------------------------------" "--------------"
check() {
  local name="$1" pattern="$2"
  local line phase
  line=$(oc get csv -A --no-headers 2>/dev/null | grep -iE "$pattern" | head -1)
  if [ -z "$line" ]; then
    printf '%-42s %-14s\n' "$name" "PENDIENTE"
  else
    phase=$(echo "$line" | awk '{print $NF}')
    if [ "$phase" = "Succeeded" ]; then
      printf '%-42s %-14s\n' "$name" "OK"
    else
      printf '%-42s %-14s\n' "$name" "$phase"
    fi
  fi
}
check "cert-manager" "cert-manager"
check "Connectivity Link" "connectivity"
check "Leader Worker Set" "leaderworker|lws"
----

== Orden de instalación

En la consola: *Ecosystem* → *Software Catalog*. Instala uno, espera *Succeeded*, sigue al siguiente (mismo orden que la lista de arriba).

== Manifiestos por operador

También puedes aplicar *uno por uno* desde la raíz del repo. Espera `Succeeded` entre cada apply (reutiliza el comando de validación).

=== cert-manager

[source,bash]
----
oc apply -f manifests/operators/cert-manager/
----

=== Connectivity Link

Si el cluster *ya* tiene Authorino Operator standalone, desinstálalo *antes* (Subscription + CSV + `operators.operators.coreos.com` de Authorino). Connectivity Link lo reinstala vía Kuadrant. No borres `rhcl-operator`.

[source,bash]
----
oc apply -f manifests/operators/connectivity-link/
----

=== Leader Worker Set

[source,bash]
----
oc apply -f manifests/operators/leader-worker-set/
----

== Verificar

Vuelve a ejecutar el comando de *Validar instalados y pendientes*. Todos deben quedar en `OK`.

NOTE: `apply-maas.sh` (xref:04-02-maas.adoc[Postgres, Gateway y modelsAsAService]) reinstala *Connectivity Link* y *Leader Worker Set* si faltan; *cert-manager no* — instálalo antes con `oc apply -f manifests/operators/cert-manager/`.
