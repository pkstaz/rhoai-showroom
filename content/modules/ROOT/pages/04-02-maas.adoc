= Postgres, Gateway y modelsAsAService

Orden:

. Postgres + secret `maas-db-config`
. Gateway `maas-default-gateway`
. `aigateway.modelsAsAService: Managed` en el DSC

== Todo en uno

Un script resuelve el módulo completo en orden: operador de Connectivity Link si falta, GatewayClass + Istio, Kuadrant, Postgres, Gateway y `modelsAsAService: Managed` en el DSC. Es idempotente: se puede re-ejecutar.

[source,bash]
----
bash manifests/apply-maas.sh
----

Con el operador ya instalado (xref:02-00-operators.adoc[módulo 2]):

[source,bash]
----
bash manifests/apply-maas.sh --skip-operator
----

=== Desde otros proyectos

Clona este repo y ejecuta el script contra el cluster donde ya hiciste `oc login`:

[source,bash]
----
git clone git@github.com:pkstaz/rhoai-showroom.git
bash rhoai-showroom/manifests/apply-maas.sh --skip-operator
----

=== GitOps

La parte declarativa está lista para GitOps como bundle kustomize (GatewayClass, Kuadrant y Postgres):

[source,bash]
----
oc apply -k manifests/maas
----

El Gateway y el patch del DSC dependen de valores del cluster (dominio, certificado, nombre del DSC), por eso los maneja el script; en un repo GitOps pasarían a ser valores parametrizados (kustomize `replacements` o parches).

== 1. Base de datos

[source,bash]
----
oc apply -f manifests/maas/maas-postgres.yaml
oc get pods -n redhat-ai-gateway-infra
----

Espera el pod de Postgres `Running`. El YAML crea el Secret `maas-db-config`.

== 2. Gateway

[source,bash]
----
bash manifests/apply-maas-gateway.sh
oc get gateway maas-default-gateway -n openshift-ingress
----

`Programmed` = `True`.

== 3. Encender MaaS en el DSC

Hasta ahora `modelsAsAService` estaba en `Removed`. Aquí se deja el AI Gateway en `Managed` y se enciende MaaS en el `DataScienceCluster`:

[source]
----
aigateway:
  managementState: Managed
  modelsAsAService:
    managementState: Managed
----

=== Instalar por terminal

[source,bash]
----
oc patch dsc default-dsc --type merge -p '{
  "spec": {
    "components": {
      "aigateway": {
        "managementState": "Managed",
        "modelsAsAService": { "managementState": "Managed" }
      }
    }
  }
}'
----

== Verificar

[source,bash]
----
oc get dsc default-dsc
oc get pods -n redhat-ai-gateway-infra
oc get pods -n redhat-ods-applications | grep -i maas
oc get aitenant -A
oc get maastenantconfig -A
----

`maas-api` / `maas-controller` en `Running`.
