= Añadir un modelo al Model Catalog

Fuente Hugging Face, *un solo modelo*: `{qwen-model}`.

== Qué se configura

[cols="1,2"]
|===
|Campo |Valor

|Catalog name
|`Qwen`

|Type
|Hugging Face (`hf`)

|Include models
|`Qwen/Qwen3-0.6B`

|ConfigMap
|`model-catalog-sources` en `rhoai-model-registries`
|===

== Instalar por terminal

[source,bash]
----
oc apply -f manifests/model-catalog-qwen.yaml
oc delete pod -n rhoai-model-registries -l component=model-catalog --ignore-not-found
----

Espera 1–2 minutos a que sincronice.

== Verificar

[source,bash]
----
oc get configmap model-catalog-sources -n rhoai-model-registries -o yaml
----

En el dashboard: *Catalog* / AI Hub → filtro `Qwen3` → debe aparecer *Qwen3-0.6B*.
