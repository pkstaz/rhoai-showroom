= AutoRAG y vector stores

CAUTION: *WIP* (Work in Progress). Este módulo aún NO se valida en lab; los pasos pueden cambiar.

AutoRAG (Technology Preview) busca el mejor patrón RAG (chunking, embeddings, retrieval, generación).
Un *optimization run* completo pide foundation 7B+ *con tool calling* y GPU. En CPU el lab deja:

* Pipeline server (módulo 17)
* pgvector remoto en `llm`
* ConfigMap `gen-ai-aa-vector-stores` → pestaña *Vector stores* en *AI asset endpoints*
* Playground *Knowledge* (upload o store existente)

== CPU vs GPU

[cols="1,2"]
|===
|Cluster |Qué hacer

|Solo CPU / Fake GPU
|pgvector + Playground Knowledge. *No* lances un optimization AutoRAG con Llama-8B.

|NVIDIA Ready
|Mismo pgvector + un modelo con `--enable-auto-tool-choice` y un embedding; luego *Gen AI studio → AutoRAG → Create run* (preset Lightweight).
|===

== Optimization (solo GPU)

UI: *Gen AI studio → AutoRAG*. Connection OGX (base URL + API key del `OGXServer`). Vector DB = pgvector. Documentos = bucket `autorag`. Test JSON = `testdata.json`. Preset Lightweight.

Foundation models necesitan tool calling en vLLM. El modelo CPU del módulo 8 *no* es un buen generador AutoRAG.
