= Operadores base

Antes de instalar OpenShift AI (primer paso de este módulo) hace falta un conjunto *base* de operadores de plataforma: los que el `DataScienceCluster` espera ya instalados.

Los operadores de MaaS (cert-manager, Connectivity Link y Leader Worker Set) van en xref:04-01-operators-maas.adoc[Prerrequisitos → Operadores MaaS] del módulo 4.

Canal y namespace: los que propone el *Software Catalog*, salvo que la tabla indique otra cosa.

== Validar instalados y pendientes

Ejecuta esto *antes* de instalar (y otra vez al final). `OK` = CSV `Succeeded`; `PENDIENTE` = aún no está o no terminó:

[source,bash]
----
printf '%-42s %-14s\n' "OPERADOR" "ESTADO"
printf '%-42s %-14s\n' "------------------------------------------" "--------------"
check() {
  local name="$1" pattern="$2"
  local line phase
  line=$(oc get csv -A --no-headers 2>/dev/null | grep -iE "$pattern" | head -1)
  if [ -z "$line" ]; then
    printf '%-42s %-14s\n' "$name" "PENDIENTE"
  else
    phase=$(echo "$line" | awk '{print $NF}')
    if [ "$phase" = "Succeeded" ]; then
      printf '%-42s %-14s\n' "$name" "OK"
    else
      printf '%-42s %-14s\n' "$name" "$phase"
    fi
  fi
}
check "OpenShift Pipelines" "pipelines"
check "Kueue" "kueue"
----

== Operadores requeridos

[cols="1,2"]
|===
|Operador |Para qué sirve

|*Red Hat OpenShift Pipelines*
|Base Tekton para habilitar *AI Pipelines* en OpenShift AI (pipelines de datos / ML desde la consola más adelante).

|*Red Hat build of Kueue*
|*GPU Booking*: colas y cuotas para que los jobs de GPU no saturen el cluster. El DSC lo deja `Unmanaged`: usa este Operator y no lo gestiona. Namespace `openshift-kueue-operator`, canal `stable-v1.4` (CSV `1.4.2`), *All namespaces*. OwnNamespace no está soportado.
|===

== Orden de instalación

En la consola: *Ecosystem* → *Software Catalog*. Instala uno, espera *Succeeded*, sigue al siguiente (mismo orden que la tabla).

== Manifiestos por operador

También puedes aplicar *uno por uno* desde la raíz del repo. Espera `Succeeded` entre cada apply (reutiliza el comando de validación).

=== OpenShift Pipelines

[source,bash]
----
oc apply -f manifests/operators/pipelines/
----

=== Kueue

El manifiesto usa canal `stable-v1.4` y OperatorGroup All namespaces (`spec: {}`). Si el Software Catalog muestra otro canal, instálalo desde ahí y actualiza el YAML.

Si la Subscription queda en `UpgradePending` sin InstallPlan (cambio de canal u OperatorGroup), bórrala y vuelve a aplicar el directorio.

[source,bash]
----
oc apply -f manifests/operators/kueue/
----

== Verificar

Vuelve a ejecutar el comando de *Validar instalados y pendientes*. Todos deben quedar en `OK`.

Los operadores de MaaS (cert-manager, Connectivity Link, Leader Worker Set) se instalan más adelante, en xref:04-01-operators-maas.adoc[Prerrequisitos → Operadores MaaS].
