= GPU

Capacidad `nvidia.com/gpu` para perfiles y GPU Booking.

Menús independientes (puedes hacer uno, los dos o ninguno):

* xref:05-01-nvidia-gpu.adoc[NVIDIA GPU Operator] — nodos con GPU real + profile `nvidia-gpu` (+ MIG nativo si aplica)
* xref:05-02-fake-gpu.adoc[Fake GPU Operator] — nodos solo CPU + profiles `fake-h200` / `fake-h200-mig`
* xref:05-03-gpu-config.adoc[GPU Config Plugin] — solo Fake: UI para reconfigurar topología/MIG

== Qué instalar según tu cluster

[cols="1,2"]
|===
|Topología |Qué hacer

|Single node *con* GPU
|Solo xref:05-01-nvidia-gpu.adoc[NVIDIA GPU Operator]. *No* Fake GPU.

|Single node *solo* CPU
|Solo xref:05-02-fake-gpu.adoc[Fake GPU Operator].

|Nodos GPU y CPU *separados*
|Puedes *ambos*: NVIDIA en GPU; Fake solo en workers CPU.

|Sin GPU / sin Fake
|Omite ambos. El modelo CPU usa `cpu-workshop`.
|===

IMPORTANT: *Nunca* instales Fake GPU en un nodo que ya tenga GPU NVIDIA (mismo nodo = conflicto). La GPU real puede estar en un *control-plane compacto* (`g6.*` / `NVIDIA-L4`, etc.): identifícala por `allocatable["nvidia.com/gpu"]`, no por el nombre del MachineSet.

En el camino *híbrido* (NVIDIA + Fake) el Helm de Fake choca con el ClusterRole `nvidia-device-plugin` del GPU Operator real. Sigue el workaround en xref:05-02-fake-gpu.adoc#_si_nvidia_gpu_operator_ya_está[Fake GPU].

NOTE: *Node Feature Discovery* (NFD) sí puedes usarlo con NVIDIA GPU Operator y Fake GPU a la vez. NFD solo etiqueta hardware real (p. ej. PCI `10de`); Fake GPU usa su propio label (`run.ai/simulated-gpu-node-pool`) en workers CPU y no choca con NFD. El NVIDIA GPU Operator suele desplegar o depender de NFD — déjalo en los nodos con GPU; no hace falta (ni conviene) forzar labels NVIDIA en el nodo Fake.

== Inventario (opcional, compartido)

[source,bash]
----
printf '%-42s %-10s %-12s %s\n' "NODO" "ROLE" "GPU_ALLOC" "NVIDIA_HINTS"
printf '%-42s %-10s %-12s %s\n' "------------------------------------------" "----------" "------------" "----------------"

oc get nodes -o json | jq -r '
  .items[] |
  . as $n |
  ($n.metadata.labels["node-role.kubernetes.io/worker"] // empty) as $w |
  ($n.metadata.labels["node-role.kubernetes.io/master"] // $n.metadata.labels["node-role.kubernetes.io/control-plane"] // empty) as $m |
  (if $w != "" then "worker" elif $m != "" then "master" else "-" end) as $role |
  ($n.status.allocatable["nvidia.com/gpu"] // "-") as $gpu |
  ([
    $n.metadata.labels["nvidia.com/gpu.product"] // empty,
    $n.metadata.labels["feature.node.kubernetes.io/pci-10de.present"] // empty
  ] | map(select(. != "")) | join(", ")) as $labels |
  "\($n.metadata.name)\t\($role)\t\($gpu)\t\($labels)"
' | while IFS=$'\t' read -r name role gpu labels; do
  printf '%-42s %-10s %-12s %s\n' "$name" "$role" "$gpu" "${labels:--}"
done
----

[source,bash]
----
export NVIDIA_GPU_NODES=$(oc get nodes -o json | jq -r '
  .items[] |
  select(
    (.status.allocatable["nvidia.com/gpu"] != null)
    or (.metadata.labels["feature.node.kubernetes.io/pci-10de.present"] == "true")
    or ((.metadata.labels["nvidia.com/gpu.product"] // "") != "")
  ) |
  .metadata.name
' | tr '\n' ' ')

export CPU_WORKER_NODES=$(oc get nodes -l node-role.kubernetes.io/worker -o json | jq -r '
  .items[] |
  select((.status.allocatable["nvidia.com/gpu"] // "0") == "0"
    or .status.allocatable["nvidia.com/gpu"] == null) |
  .metadata.name
' | tr '\n' ' ')

echo "NVIDIA_GPU_NODES=${NVIDIA_GPU_NODES:-(ninguno)}"
echo "CPU_WORKER_NODES=${CPU_WORKER_NODES:-(ninguno)}"
----
