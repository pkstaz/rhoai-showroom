= Desplegar modelo

Publica un modelo en MaaS. Elige *una o más* rutas (como el módulo 5):

* xref:08-01-deploy-cpu.adoc[CPU] — modelo LLM con llm-d / vLLM CPU. *Camino por defecto del lab.*
* xref:08-02-deploy-gpu.adoc[GPU] — vLLM CUDA en GPU NVIDIA real (módulo 5 NVIDIA). Fake GPU *no* sirve para inferencia.
* xref:08-03-deploy-external.adoc[Modelo externo] — OpenAI-compatible fuera del cluster (TMM u otro). Name, endpoint y API key los da el instructor *en cada sala*.

== Qué instalar según tu cluster

[cols="1,2"]
|===
|Situación |Qué hacer

|OpenTLC / CPU only
|xref:08-01-deploy-cpu.adoc[CPU]. Luego módulo 9.

|Hay GPU NVIDIA (módulo 5.1)
|CPU *y/o* xref:08-02-deploy-gpu.adoc[GPU].

|Vas a evaluar / red-team sin GPU local
|xref:08-03-deploy-external.adoc[Modelo externo] (TMM). EvalHub (12) apunta a ese endpoint.
|===

Las tres rutas crean o reutilizan el proyecto `llm` y un `MaaSModelRef`. La subscription (módulo 9) es *por modelo*.
