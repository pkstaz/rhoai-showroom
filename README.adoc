= OpenShift AI 3.5

Workshop Showroom: instala OpenShift AI 3.5.1, MaaS, fake/real GPU, GPU Booking, publica Qwen3-0.6B en CPU con llm-d, y continúa con FinOps, guardrails, registry, AutoML/AutoRAG, Prompt Registry, MCP, AgentOps, Skills y Garak/ART.

* Lab (GitHub Pages): https://pkstaz.github.io/rhoai-showroom/modules/00-00-intro.html
* Instalación: **comando / `oc apply` primero**; UI al final de cada módulo

== Desarrollo local

[source,sh]
----
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----

O:

[source,sh]
----
npm install --global @antora/cli@3.1 @antora/site-generator@3.1
antora generate default-site.yml
----

El contenido está en `content/modules/ROOT/pages/`.
Los manifiestos de apoyo están en `manifests/` (raíz del repo).
